# Contributing

This repo builds ferritefw.dev and the blog. For the firmware or Console, use their own repos: [ferrite](https://github.com/FerriteFW/ferrite/issues), [console](https://github.com/FerriteFW/console/issues).

## Issues

A typo, a broken link, something unclear or out of date: open an [issue](https://github.com/FerriteFW/ferrite-website/issues). Screenshots help.

## Pull requests

Pull requests are welcome, with the contributor agreement.

- **The agreement:** read [CLA.md](CLA.md) and tick its box in the pull request template. Once, on your first pull request: it then covers everything you send to the project: Ferrite, Ferrite Console, the manual and the website. You keep your copyright. Your name goes in [CLA-SIGNED.md](CLA-SIGNED.md).
- **Small and focused:** one fix per pull request. For a new page or a bigger change, open an issue first.
- **Only what's built:** the site describes what Ferrite does today, plainly. No claims about features that aren't released.
